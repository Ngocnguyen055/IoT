Hướng dẫn chạy sản phẩm.
1. Đi đến thư mục chứa file app.py
2. Click vào đường dẫn của thư mục, gõ "cmd" để mở cmd tại thư mục
	2.1. Kiểm tra Python và cài Flask
chạy các lệnh sau:
python --version
cd /d C:\IOT_Ngoc\server (thay đổi theo đường dẫn trên máy)
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install Flask
	
	2.2. Thiết lập mật khẩu và khoá
set "DEVICE_KEY=3445fc58fe14088666f4c8e49ea8a3c167f4f8df72004eeacbcf771f18c820ce"
set "ADMIN_PASSWORD=ngocnguyen123"
set "SESSION_SECRET=a29243364ce0b85893337a266970a71405522a8ccc0bd25de88cba497f6a216b"

	2.3. Chạy Flask
Tại CMD vừa cấu hình:

python app.py

Nếu thành công sẽ có dòng tương tự:
Running on http://127.0.0.1:5000
Mở http://127.0.0.1:5000. Bạn sẽ thấy trang đăng nhập. Đăng nhập bằng ADMIN_PASSWORD. Không đóng cửa sổ CMD Flask.
Kiểm tra API tracking: Sau khi đăng nhập, mở:
http://127.0.0.1:5000/api/track?device_id=ngoc-01&hours=24
Nếu trả JSON với trường points (có thể là []): server mới có API tracking.
Nếu 404 Not Found: đang chạy nhầm app.py hoặc chưa cập nhật mã; kiểm tra findstr /n /i "api/track" app.py.
Nếu 401: cần đăng nhập và thử lại.

3. Cài và chạy Cloudflare Tunnel

	3.1. Cài cloudflared

Mở cmd bằng quyền admin rồi nhập: winget install --id Cloudflare.cloudflared -e
Nhập Y rồi Enter
Đóng cmd rồi mở lại
Kiểm tra:

cloudflared --version

Nếu báo không nhận lệnh, kiểm tra PATH hoặc chạy đúng đường dẫn cloudflared.exe. cloudflared không phải là gói Python, không cài bằng pip.

	3.2. Tạo Quick Tunnel
Bắt buộc Flask ở mục 2 đang chạy trên port 5000. Mở CMD thứ hai rồi nhập:
cloudflared tunnel --url http://127.0.0.1:5000
